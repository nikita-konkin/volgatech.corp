# Волгатех.Коллектив — версия для iPhone

**Сайт: https://nikita-konkin.gitverse.site/volgatech.corp/**
(зеркало: https://konkin-nikita.ru/volgatech.corp/)

Приложение «Личный кабинет работника» ПГТУ (Волгатех) для iPhone: открывается
в Safari и ставится на экран «Домой», как обычное приложение. App Store не
нужен.

## Что умеет

- **Расписание** на неделю и **обзор недели**: все пары, окна, часы;
- **экзамены** по учебным годам;
- **профиль**: должности, ставки, стаж;
- **служебная записка по иностранным группам** (.docx) за месяц;
- светлая и тёмная тема; без связи показывает то, что загружено раньше.

## Как установить на iPhone

1. Откройте сайт в **Safari**.
2. Нажмите **Поделиться** (квадрат со стрелкой) → **На экран «Домой»** →
   **Добавить**.
3. Запустите «Волгатех» с экрана «Домой» и войдите с логином и паролем от
   личного кабинета. У приложения на экране «Домой» свои данные, отдельно от
   Safari, поэтому входить нужно именно в нём.

Подходит для любого iPhone, от первого SE до 17 Pro Max, вертикально и
горизонтально.

## Чем отличается от версии для Android

- «Почта» открывает веб-почту в новой вкладке: встроенного почтового клиента
  нет, сервер почты не принимает запросы с веб-страниц;
- нет блокировки по Face ID или PIN-коду;
- обновлять ничего не нужно: новая версия загружается сама при следующем
  запуске.

Версия для Android (APK) — на
[странице релизов](https://github.com/nikita-konkin/volgatech.corp/releases/latest).

## Данные

Логин и пароль уходят только на сервер университета (`api.volgatech.net`).
Расписание и профиль хранятся в браузере на телефоне; больше приложение ничего
никуда не отправляет.
