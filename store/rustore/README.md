# RuStore submission checklist

- [ ] Merge the privacy policy into the default branch and verify the public URL. Use [the privacy policy](../../PRIVACY.md) for the console privacy policy field and confirm it also opens from Settings.
- [ ] Run the **RuStore** workflow with a ref containing this implementation. Download and extract the workflow artifact and upload its universal APK under the new version. For 0.5.8 the APK is named `volgatech-rustore-0.5.8-5025.apk`.
- [ ] Copy the app name, short description, full description, category, age rating and tags from the corresponding sections of [listing.md](listing.md). Confirm the age classification in the console.
- [ ] Copy «Что нового» from [listing.md](listing.md) into the release notes. Use «Частые вопросы» for FAQ or support replies as applicable.
- [ ] Upload the app icon, representative Android screenshots without staff data, and the university authorization to use the name and logo. Provide the support email in the app card.
- [ ] In «Безопасность данных пользователя», complete «Категории и типы данных» from [data-safety.md](data-safety.md). For each permission shown in «Чувствительные разрешения», use the matching entry from [permissions.md](permissions.md).
- [ ] Paste [moderator-note.md](moderator-note.md) into the moderator comment. Arrange reviewer access through the console's restricted review fields when needed. Keep credentials out of public fields and repository files.
- [ ] Review the app card and submit the version for moderation.
