# Безопасность данных пользователя

| Категория и тип данных | Для чего используются | Передача с устройства |
| --- | --- | --- |
| Личная информация — логины, данные аутентификации | Вход в кабинет, почту и раздел «Учебная нагрузка» | Университетские API `api.volgatech.net` или `test-api.volgatech.net`, Exchange `mail.volgatech.net`, портал `portal.volgatech.net` соответственно |
| Личная информация — имя, фото, сведения о работе и подразделении | Профиль и рабочие данные | Получение с университетского API; связанные данные и часы сохраняются на портале при подтверждении формы |
| Личная информация — имена и рабочие адреса корреспондентов | Поиск получателей и адресация | Запросы и выбранные адресаты передаются `mail.volgatech.net` |
| Идентификаторы — идентификатор сотрудника, токены сеанса | Запросы данных сотрудника и поддержание сеанса | Университетский API; веб-сеанс портала использует данные аутентификации этого портала |
| Сообщения — письма, темы, отправители, получатели, почтовые папки и состояние писем | Чтение, поиск, отправка, управление ящиком и уведомления | Обмен с `mail.volgatech.net`; отправленные письма доставляются адресатам. Внешние изображения загружаются с адресов в письме по запросу пользователя |
| Файлы и документы — вложения и выбранные пользователем файлы | Чтение, отправка, сохранение и открытие | Обмен вложениями с `mail.volgatech.net`; сохранение и передача другой программе по выбору пользователя |
| Файлы и документы — формы, отчёты и настройки рабочих документов | Учёт часов и подготовка документов | Формы и часы передаются `portal.volgatech.net` по подтверждению. Экспортируемые отчёты передаются только по действию пользователя |
| Календарь — расписание занятий и экзаменов | Просмотр, виджет, напоминания и экспорт | Данные получаются с университетского API; рассчитанные часы можно отправить на портал. Файл календаря передаётся по действию пользователя. Чтение календаря устройства не требуется |
| Данные о работе приложения — журнал ошибок | Просмотр и диагностика | Локально. Пользователь может отправить отчёт выбранным способом |
| Локальные напоминания и почтовые уведомления | Показ ближайшего занятия или нового письма | Уведомления формируются на устройстве; фоновая проверка писем обращается к Exchange |

Ссылка на политику открывает GitHub в браузере. Переходы по внешним ссылкам и системное меню передачи открывают выбранный пользователем адрес или приложение. Встроенного канала аналитики или рекламы в сборке нет.
