# Примечание для модератора

Приложение — рабочий кабинет сотрудников Поволжского государственного технологического университета (ПГТУ). Для входа нужна университетская учётная запись сотрудника, поэтому для проверки ПГТУ выдал тестовую учётную запись:

- Кабинет: логин «…», пароль «…»
- Почта: логин «…», пароль «…»
- Портал («Учебная нагрузка»): логин «…», пароль «…»

Разрешение университета на использование его названия и логотипа приложено к этому комментарию.

Собственных учётных записей в приложении нет. При выходе удаляются данные сеанса, кэш кабинета, сохранённые учётные данные почты и временные вложения. Для удаления оставшихся настроек и локальных данных можно очистить данные приложения в Android или удалить его. Университетская учётная запись управляется ПГТУ.
