# Примечание для модератора

Для проверки нужна действующая учётная запись сотрудника ПГТУ. Владелец приложения прикладывает разрешение университета на использование его названия и логотипа.

Собственных учётных записей в приложении нет. При выходе удаляются данные сеанса, кэш кабинета, сохранённые учётные данные почты и временные вложения. Для удаления оставшихся настроек и локальных данных можно очистить данные приложения в Android или удалить его. Университетская учётная запись управляется ПГТУ.
