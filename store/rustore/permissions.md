# Разрешения сборки RuStore

Классы определены по [справочнику RuStore](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/new-version-app/declare-app-permissions/permission-types) и типам разрешений Android. Консоль показывает окончательный список разрешений, которые нужно задекларировать.

| Разрешение | Класс | Обоснование |
| --- | --- | --- |
| `android.permission.INTERNET` | Безопасное | Нужен доступ к университетскому кабинету, Exchange и порталу нагрузки. См. [API](../../app/lib/core/api_client.dart), [Exchange](../../app/lib/mail/ews_client.dart) и [портал](../../app/lib/data/portal_workload_client.dart). |
| `android.permission.USE_BIOMETRIC` | Безопасное | По желанию сотрудника приложение запрашивает системную проверку личности при открытии. См. [блокировку приложения](../../app/lib/core/app_lock.dart). |
| `android.permission.POST_NOTIFICATIONS` | Чувствительное | Позволяет показывать напоминания о занятиях и уведомления о входящих письмах при включении соответствующих функций. См. [напоминания](../../app/lib/core/notifications.dart) и [фоновую проверку почты](../../app/lib/mail/mail_background.dart). |
| `android.permission.RECEIVE_BOOT_COMPLETED` | Безопасное | После перезапуска устройства Android восстанавливает запланированные напоминания о занятиях и фоновые задания проверки почты. См. [регистрацию получателей](../../app/android/app/src/main/AndroidManifest.xml) и [планирование почтовой проверки](../../app/lib/mail/mail_background.dart). |
| `android.permission.USE_EXACT_ALARM` | Безопасное по справочнику RuStore | На Android 13 и новее даёт возможность напомнить о занятии в выбранное время и обновить виджет по расписанию. См. [планирование уведомлений](../../app/lib/core/notifications.dart) и [виджет](../../app/android/app/src/main/kotlin/net/volgatech/volgatech_pro/LessonWidget.kt). |
| `android.permission.SCHEDULE_EXACT_ALARM` | Чувствительное | В манифесте ограничено Android 12/12L и более ранними версиями. На Android 12 и 12L поддерживает точное время напоминания о занятии, если система разрешает точные будильники. См. [планирование уведомлений](../../app/lib/core/notifications.dart). |
| `android.permission.VIBRATE` | Безопасное | Библиотека локальных уведомлений использует вибрацию для оповещений, если это допускают настройки канала на устройстве. См. [каналы уведомлений](../../app/lib/core/notifications.dart) и [почтовые уведомления](../../app/lib/mail/mail_background.dart). |
| `android.permission.FOREGROUND_SERVICE` | Безопасное | Входит в объединённый манифест через библиотеку фоновых задач WorkManager, которую приложение использует для периодической проверки почты. Проверка регистрируется как периодическое задание. См. [регистрацию задания](../../app/lib/mail/mail_background.dart). |
| `android.permission.FOREGROUND_SERVICE_SHORT_SERVICE` | Класс RuStore не установлен | Добавляется Android-плагином WorkManager вместе с декларацией короткой службы. Код приложения планирует обычную периодическую проверку писем и не запускает эту службу напрямую. По [документации Android](https://developer.android.com/reference/android/content/pm/ServiceInfo#FOREGROUND_SERVICE_TYPE_SHORT_SERVICE) для этого типа достаточно `FOREGROUND_SERVICE`. См. [регистрацию задания](../../app/lib/mail/mail_background.dart). |
| `android.permission.USE_FINGERPRINT` | Безопасное, устаревшее в Android | Добавляется AndroidX для совместимости системной проверки отпечатка на старых версиях Android. См. [блокировку приложения](../../app/lib/core/app_lock.dart). |
| `android.permission.WAKE_LOCK` | Безопасное | WorkManager использует его для завершения фонового задания, когда экран выключен. Задание проверяет новую почту, если пользователь включил оповещения. См. [фоновую проверку почты](../../app/lib/mail/mail_background.dart). |
| `android.permission.ACCESS_NETWORK_STATE` | Безопасное по типу Android (Normal) | WorkManager проверяет наличие сети перед запуском фонового запроса к Exchange. См. [сетевое условие задания](../../app/lib/mail/mail_background.dart). |
| `net.volgatech.volgatech_pro.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` | Чувствительное по типу подписи; класс собственных разрешений уточняется в Консоли | AndroidX добавляет приложению собственное разрешение уровня подписи для защиты внутренних динамических получателей. Оно ограничивает отправителей внутренних событий, используемых инфраструктурой фоновых заданий. См. [фоновую проверку почты](../../app/lib/mail/mail_background.dart). |
