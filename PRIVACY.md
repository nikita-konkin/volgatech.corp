# Политика конфиденциальности приложения «Волгатех.Коллектив»

Приложение разработано сотрудником Поволжского государственного технологического университета (ПГТУ) с разрешения университета для его сотрудников. Для входа используется существующая университетская учётная запись. Приложение не создаёт собственных учётных записей.

## Какие данные обрабатываются и зачем

- **Вход и профиль.** Логин и пароль передаются по HTTPS университетскому API `api.volgatech.net` или `test-api.volgatech.net` при выборе тестового сервера. Пароль основного кабинета приложение не сохраняет. Токены доступа и обновления сессии, а также числовой идентификатор сотрудника хранятся в защищённом хранилище платформы (на Android используются зашифрованные настройки). При выборе «Запомнить логин» имя пользователя сохраняется отдельно в обычных настройках. С того же API приложение получает и отображает профиль, включая имя, фотографию, подразделения и сведения о работе и нагрузке.
- **Расписание и экзамены.** Университетский API передаёт расписание и сведения об экзаменах, включая даты, время, дисциплины, группы и аудитории. Приложение показывает эти данные, формирует локальные напоминания и виджет и позволяет сформировать файл календаря для экспорта. Расписание также используется для подготовки отчётов и заполнения учебной нагрузки.
- **Почта.** Встроенный клиент обращается к `mail.volgatech.net` по HTTPS через Exchange. Для повторных подключений он сохраняет принятые сервером логин и пароль в защищённом хранилище платформы. Сервер получает запросы на поиск и изменение почты, а также письма с адресами, темами, текстом и вложениями при отправке. Приложение получает содержимое и служебные сведения почтового ящика, результаты поиска, данные получателей из адресной книги и сведения о новых письмах для локальных уведомлений. В сборках с веб-почтой вход и работа с письмами происходят на том же сервере через OWA. При показе внешних картинок по запросу пользователя сетевые запросы идут к указанным в письме адресам. При переходе по ссылке её открывает браузер.
- **Учебная нагрузка.** Встроенный браузер передаёт учётные данные для входа на `portal.volgatech.net` по HTTPS. Приложение не сохраняет пароль портала в своём хранилище. Веб-компонент может сохранять файлы cookie и данные сеанса. Приложение читает строки месячной формы и связанные сведения о подразделениях и дисциплинах, сопоставляет их с расписанием и отправляет введённые или рассчитанные часы на портал после подтверждения пользователем.
- **Уведомления и блокировка.** Android показывает локальные напоминания о занятиях и, при включении функции, уведомления о новых письмах на основе фоновой проверки Exchange. В уведомлениях могут отображаться сведения о занятии, отправитель и тема письма. Проверкой отпечатка, лица или кода устройства управляет операционная система, которая возвращает приложению результат проверки.
- **Файлы.** Для просмотра вложения загружаются с почтового сервера во временное хранилище приложения. При отправке письма выбранные файлы передаются Exchange. Файлы календаря, отчёты и другие документы, которые пользователь сохраняет или открывает через другое приложение, передаются выбранному приложению или месту хранения по его действию.
- **Диагностика.** На устройстве хранится до 20 записей об ошибках, включая тип ошибки, фрагмент стека, версию приложения, время и повторяемость. Автоматической отправки нет. Пользователь может посмотреть, удалить или передать журнал через системное меню.

## Другие сетевые обращения

Ссылка на эту политику открывает `github.com` в браузере. В сборках с встроенным обновлением приложение запрашивает сведения о выпуске на `api.github.com` и скачивает APK через `github.com` и его перенаправления без университетских учётных данных. В сборке RuStore обновления доставляет магазин. URL `schemas.microsoft.com` и `schemas.xmlsoap.org` в коде обозначают пространства имён XML, сетевые запросы туда приложение не отправляет.

В списке зависимостей `app/pubspec.yaml` проверены сетевые, почтовые и веб-компоненты (`dio`, `enough_mail`, `webview_flutter`, `webview_flutter_android`), хранилище, средства работы с файлами и системными функциями, локальные уведомления и фоновые задачи. В зависимостях приложения нет SDK аналитики, рекламы и автоматической отправки отчётов. Сторонние библиотеки используются для перечисленных функций, и приложение не передаёт им данные для самостоятельной аналитической или рекламной обработки.

## Хранение и удаление

Данные сессии хранятся до выхода или сброса сессии. Приложение сохраняет локальные копии профиля, фотографий и расписания для работы без сети, обновляет их при получении свежих данных и очищает при выходе. Файлы во временном хранилище могут быть удалены системой. Выход из кабинета удаляет токены и идентификатор, очищает кэш приложения, сохранённые почтовые учётные данные и временные копии вложений. Выход из почты также удаляет почтовые учётные данные и временные копии вложений.

Настройки, включая запомненный логин и журнал ошибок, могут сохраняться после выхода. Запоминание логина можно отключить на экране входа, а журнал удалить в настройках. Чтобы удалить оставшиеся данные приложения и сеансы встроенного браузера на Android, очистите данные приложения в системных настройках или удалите приложение. Файлы, сохранённые за пределами приложения, удаляются отдельно. Данные в университетских системах подчиняются правилам хранения ПГТУ. Выход или удаление приложения не удаляет серверную учётную запись, письма или документы. По вопросам хранения и удаления таких данных обращайтесь в университет.

## Дети, изменения и контакты

Приложение предназначено для сотрудников ПГТУ. Специальных функций для детей и регистрации детей нет.

При изменении обработки данных актуальная редакция публикуется по ссылке в настройках приложения и в карточке RuStore.

По вопросам конфиденциальности можно обратиться через раздел Issues репозитория https://github.com/nikita-konkin/volgatech.corp или по адресу электронной почты, указанному в карточке приложения в RuStore.
